# SerialBridge для Android

Мобильная консоль беспроводного моста SerialBridge (ESP32): вывод отлаживаемого МК,
отправка строк, панель напряжений ADS1115, питание МК, сброс, линия AUX — те же возможности
и те же команды «:…», что у `serbridge.exe` на Windows. Прошивку моста менять не нужно.

## Сборка без Android Studio — через GitHub

1. На github.com: **New repository** → имя, например `serbridge-android`, тип **Public**
   (тогда APK скачивается на телефон по прямой ссылке без входа в GitHub) → **Create repository**.
2. На странице пустого репозитория: **uploading an existing file** (или Add file → Upload files).
3. Распаковать архив и перетащить в окно браузера **всё содержимое** папки `SerBridgeMobile`
   (папки `.github`, `app`, `signing` и файлы рядом с ними — не саму папку и не zip).
4. Внизу **Commit changes**.
5. Вкладка **Actions** — сборка запустится сама и идёт 3–5 минут (зелёная галочка — готово).
6. APK: вкладка **Releases** → «Последняя сборка» → `serbridge.apk`, или прямая ссылка
   `https://github.com/ИМЯ/serbridge-android/releases/latest/download/serbridge.apk`.

Каждая следующая загрузка изменённых файлов собирает новую версию; она ставится поверх старой
(ключ подписи постоянный — `signing/debug.keystore.b64`).

Если папка `.github` не загрузилась (в репозитории нет `.github/workflows/build.yml`),
создайте файл вручную: Add file → Create new file → имя `.github/workflows/build.yml`,
содержимое — из архива.

## Установка на телефон

Открыть ссылку на APK в браузере телефона → скачать → открыть файл. Android попросит
разрешить установку из этого источника (браузера или файлового менеджера) — разрешить.
Нужен Android 7.0 или новее.

## Работа

* Телефон должен быть в той же сети Wi-Fi, что и мост (или подключён к сети самого моста
  `SerBridge-XXXX`, адрес 192.168.4.1). При первом запуске приложение ищет мост само;
  адрес запоминается.
* Строка без двоеточия уходит в МК; команды начинаются с «:» — как в консоли Windows:

| Команда | Действие |
|---|---|
| `:find`, `:connect 192.168.1.50` | найти мост / подключиться по адресу |
| `:status` | состояние моста |
| `:baud 57600` | скорость UART моста |
| `:eol lf\|crlf\|cr\|none` | окончание отправляемых строк |
| `:time`, `:hex` | метки времени / шестнадцатеричный вывод |
| `:tx 01 02 FF` | отправить байты |
| `:reset [мс]` | сбросить МК (XP2.5) |
| `:aux [0\|1\|pulse мс]` | доп. линия XP2.6 |
| `:v …` | вольтметр: `reset`, `mm`, `name`, `cal`, `on`, `off`, `rate`, `alarm` |
| `:bridge <команда>` | команда самому мосту (ssid, pass, name, tsense, tcal, help) |
| `:clear`, `:share` | очистить экран / поделиться журналом |

* Панель над выводом: питание МК и каналы ВХ1…ВХ4 с минимумом и максимумом за сеанс.
  Нажатие — показать/скрыть мин/макс, долгое нажатие — сбросить их.
* Долгое нажатие на кнопку ➤ — история отправленных строк. Остальное — в меню ⋮.
* Пока приложение свёрнуто, связь разрывается, а мост копит вывод МК (до 32 КБ) и отдаёт его
  при возвращении в приложение.
* Мост рассчитан на одного клиента: не подключайте телефон и консоль Windows одновременно.
